## Español

Simulación visual inofensiva creada en **Python 3.15.2** (compilada a C) para practicar el uso de la API gráfica de Windows (GDI).

### Qué hace este programa
- Ejecuta efectos gráficos temporales en pantalla (rastros de íconos, ondas de color, efecto terremoto y pantalla espejo).
- Abre el Administrador de tareas.
- Finaliza con un clásico Rickroll en el navegador.

### Requisitos del sistema
- **Compilado con:** Python 3.15.2.
- **Compatible con:** Windows 8, Windows 8.1, Windows 10 y Windows 11 (64-bit).
- **No compatible con Windows 7** o anteriores.

## English

Harmless visual simulation built with **Python 3.15.2** (compiled to C) to practice using the Windows Graphics Device Interface (GDI) API.

### What this program does
- Runs temporary on-screen graphical effects (icon trails, color waves, screen shake/earthquake effect, and mirror screen).
- Opens the Windows Task Manager.
- Ends with a classic Rickroll in the web browser.

### System Requirements
- **Built with:** Python 3.15.2.
